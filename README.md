# Requêtez une base de données avec SQL

## Contexte
Projet réalisé dans le cadre du bootcamp Analyse de données d’OpenClassrooms.  
Dans ce scénario, j’interviens pour une entreprise du secteur de l’assurance afin d’analyser des données de contrats habitation et répondre à des besoins d’analyse à l’aide de SQL.

## Objectif
Concevoir une base de données relationnelle, charger les données, puis rédiger des requêtes SQL afin d’extraire des indicateurs fiables et exploitables pour l’analyse et le reporting.

## Données
- Données de contrats clients (fichiers CSV)
- Référentiel géographique des régions françaises
- Dictionnaire des données complété et documenté

## Outils
- SQL
- SQLite
- SQL Power Architect (schéma relationnel)
- Fonctions SQL : SELECT, WHERE, JOIN, GROUP BY, ORDER BY
- Fonctions d’agrégation : COUNT, AVG, SUM, MIN, MAX

## Méthodologie
- Analyse des fichiers sources et compréhension des types de données  
- Création et complétion du dictionnaire des données  
- Conception d’un schéma relationnel normalisé  
- Génération du code SQL de création des tables  
- Chargement et vérification des données dans la base  
- Rédaction progressive de requêtes SQL pour répondre aux questions métier  
- Vérification et interprétation des résultats obtenus  

## Ce que j’ai fait
- Création d’une base de données relationnelle à partir de fichiers CSV  
- Mise en place du schéma relationnel et des contraintes  
- Rédaction de requêtes SQL simples puis avancées (jointures, agrégations)  
- Analyse des contrats par surface, prix, région, département et commune  
- Rédaction d’un support de présentation synthétisant la méthodologie, les requêtes SQL et les résultats  

## Résultat
Une base de données fonctionnelle et un ensemble de requêtes SQL permettant d’obtenir des indicateurs fiables sur les contrats d’assurance habitation, utilisables pour l’analyse et le reporting métier.
